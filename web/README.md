# calc_size web

`calc_size` 的网页版：选择本地文件/文件夹，在浏览器中计算大小，以可展开的目录树展示，支持点击列头排序。

- 纯静态、零依赖：HTML + CSS + 原生 JavaScript（ES Modules），无构建步骤。
- 所有计算均在浏览器本地完成，不会上传任何数据。
- 界面带大小比例条与动效（级联入场、展开补间、拖拽遮罩等），遵循 `prefers-reduced-motion` 弱化动效偏好。

## 使用

- 点「选择文件或文件夹」，在弹出菜单里选「文件…」或「文件夹…」。
  浏览器原生对话框无法在同一个窗口里混选文件和文件夹，所以做成一个按钮下的两个入口；
  文件夹每次限选一个（同样是浏览器限制）。
- 把**多个文件和文件夹混合**直接拖进页面即可一次多选——这是浏览器唯一支持混合多选的机制。
- 多次选择会**累计**到列表；重复选择同一路径时用最新结果覆盖；点「清空」全部移除。
- 列头「名称 / 大小」可点击排序：再次点击切换升降序，箭头指示当前方向；
  目录始终排在文件前面（资源管理器习惯）。
- 目录行点 ▸/▾（或目录名）展开/折叠，支持任意层级；目录显示所有后代文件的大小之和。

## 本地预览

ES Modules 必须通过 HTTP 访问（直接双击 `index.html` 会被浏览器的 CORS 规则拦截），
任选其一：

```shell
python -m http.server 8000   # 打开 http://localhost:8000
# 或
npx serve .
```

## 运行测试

核心逻辑（单位换算、建树、排序）带单元测试，需要 Node ≥ 20（无需安装任何依赖）：

```shell
npm test        # 等价于 node --test
```

## 与命令行版的差异

- 浏览器枚举不到的文件（无权限、系统隐藏文件）与空目录不会出现在结果中，
  数字可能因此略有差异；网页版不存在"-1"错误值，读不到的直接缺失。
- 单位换算与 Go 版一致（1024 进制、严格大于 1024 才进位、两位小数），
  但补上了 Go 版缺失的 TB 档（B → KB → MB → GB → TB → PB）。
